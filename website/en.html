Everyday actions in Finder

Create files from templates

Import and rename multiple templates with the same extension. The context menu shows each extension and template name.

Copy or move files

Send selected items to a favorite folder or choose a destination for this operation.

Copy paths or open Terminal

Copy selected paths or right-click the background to copy the current folder path. You can also open Terminal there.

Arrange the menu your way

Drag commands into order and choose which ones appear. Set the app’s language and appearance manually or follow macOS.

Getting started

  1. Download and unzip RightMouse from GitHub Releases, then drag it into Applications.
  2. Open RightMouse and use Extension Settings to enable its Finder extension in macOS System Settings.
  3. Right-click the background of a local folder and choose New File.

Check for updates in General → Version & Support to install published Sparkle updates in the app.

Homebrew

After the first GitHub Release and cask sync, use Homebrew to install or upgrade.

brew tap echo-braveshine/rightmouse https://github.com/Echo-BraveShine/RightMouse.git
brew install --cask echo-braveshine/rightmouse/rightmouse
brew upgrade --cask --greedy echo-braveshine/rightmouse/rightmouse
